EXPERIMENT 02 · LIKELIHOOD FIELD

Laser rays on an occupancy map

Choose any map from the repository's 2D_maps/ folder, then set the sensor's field of view, ray count, and maximum range. Maps use the script's 4×4 reduction.

Parameters

LIKELIHOOD FIELD
Map

White: free · black: occupied · gray: unknown. Map coordinates use grid cells.

Robot pose in map

x is the map row; y is the map column, matching the Python script. The pose must be in a free cell.

Laser sensor
Hit model

The field and laser endpoint likelihoods update using this σ.

Mixture weights

Weights are normalized to sum to 1 for each run. Current effective weights: 0.900 / 0.050 / 0.050.

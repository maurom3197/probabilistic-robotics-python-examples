DALLA TEORIA AL CODICE

Che cosa stai osservando?

1. Un comando, più esiti

Il comando u = [v, ω] viene perturbato dal rumore. Ogni campione evolve dalla stessa posa iniziale con nuove perturbazioni a ogni passo Δt.

2. La tua funzione Python

Il browser esegue con Pyodide un’esportazione della funzione del repository, senza Matplotlib. Una forma equivalente e numericamente stabile gestisce anche ω = 0.

3. Disegno e calcolo separati

Three.js visualizza i risultati. Pan, zoom, orientamenti e riproduzione cambiano solo la vista; per calcolare nuovi risultati devi premere Esegui.

* Ellisse costruita dalla covarianza campionaria con fattore χ²₂ = 5,991: rappresenta il 95% per una distribuzione gaussiana bivariata. Una nube non gaussiana non garantisce questa copertura. Per mantenere la vista leggera vengono disegnati al massimo 1.500 campioni; le statistiche usano tutti i campioni.

Il primo avvio scarica Python e NumPy da un CDN. Nessun server esegue i tuoi esperimenti: i calcoli avvengono sul tuo dispositivo. Per hosting interamente su GitHub Pages è disponibile lo script di copia delle risorse descritto nelle istruzioni.
